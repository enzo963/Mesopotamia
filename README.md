#  Modern UI & Enki AI Showcase

A modern, fully responsive UI component library built with pure **HTML5** and **CSS3**. It seamlessly blends sleek glassmorphism, fluid micro-interactions, and high-performance UX standards without relying on heavy external frameworks.

---

##  Key Features

| Feature | Description & Implementation |
| --- | --- |
| **Glassmorphic Design** | Fixed transparent navigation bar featuring `backdrop-filter` blur effects and soft borders. |
| **Enki AI Component** | Advanced visual display showcasing rotating conic-gradient rings and orbiting particle animations. |
| **Fully Responsive** | Built-in media queries optimized across all viewports (Desktop, Tablet, and Mobile down to 480px). |
| **Accessibility-First** | Respects system settings with `prefers-reduced-motion` fallbacks for motion sensitivity. |
| **Zero Dependencies** | Lightweight, native CSS written from scratch without Bootstrap or Tailwind. |

---

##  Included Components

* **Hero & Glass Navigation:** Floating header with shine hover transitions and high-contrast landing section layouts.
* **Enki AI Feature Section:** Interactive AI showcase utilizing dynamic `conic-gradient` borders and continuous scan lines.
* **Game Showcase Section:** Product presentation cards driven by CSS Grid/Flexbox with directional entrance animations (`slideUp`, `slideLeft`).
* **Team Section:** Interactive card grid displaying circular avatars, hover elevation effects, and custom social links.
* **Global Footer:** A structured 4-column CSS Grid footer equipped with custom animated link underlines.

---

##  Tech Stack

* **HTML5:** Semantic markup structure designed for optimal accessibility and search engine readability.
* **CSS3:** Built using modern layout modules (Flexbox, CSS Grid), custom `@keyframes`, and advanced color gradients.
